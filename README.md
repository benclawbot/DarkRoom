# DarkRoom

DarkRoom is a local-first, mobile-compatible photo library and editor. There is no authentication and no cloud photo storage: originals, albums, ratings, favorites and edit metadata remain in the browser's IndexedDB on the current device.

## Features
- Multi-photo device import and local IndexedDB persistence
- Search, sorting, recent photos, favorites and 1–5 star ratings
- Albums with open, add/remove membership, rename and delete workflows
- Nondestructive Light, Color, Effects and Detail adjustments
- Rotate and flip transforms
- Shared preview/export render pipeline
- Zoomable/pannable photo workspace with fixed editing controls, including pinch gestures on mobile
- Local storage/quota reporting and complete local-library deletion
- JPEG export/share and installable/offline PWA shell
